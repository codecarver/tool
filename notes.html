Notes (Markdown)

Editor catatan WYSIWYG dalam format Markdown. Buka folder lokal di kiri, edit di kanan, auto-save.

Belum ada folder dibuka

    Klik Buka Folder untuk memilih folder lokal (browser akan meminta izin). File .md/.txt akan tampil di kiri. Klik file untuk membuka; ketik untuk mengedit. Format toolbar (tebal/miring/judul/daftar) disimpan sebagai Markdown. Di dalam daftar, tekan Tab untuk membuat sub-daftar (nested) dan Shift+Tab untuk naik level. Untuk blok kode multi-baris: klik tombol ▤ Kode (atau seleksi teks multi-baris lalu klik). Di dalam blok, Enter = baris baru, Tab = 2 spasi, dan Enter di baris kosong untuk keluar dari blok. Ada juga warna teks & highlight latar (pilih teks dulu), sisip tanggal/waktu, bagian lipat/collapsible, tabel, dan ekspor PDF. Auto-save menulis kembali ke file otomatis. Butuh browser berbasis Chromium (Chrome/Edge) untuk akses folder.
