Notes (Markdown)

A WYSIWYG Markdown notes editor. Open a local folder on the left, edit on the right, auto-save.

How to use
  • Click Open Folder in the sidebar to pick a local folder. .md/.txt files appear there; click to open, or use the ⋯ button to rename/delete.
  • Type to edit. Toolbar: B/I/S for inline format; ☰▾ for lists; ＋▾ to insert link, divider, code, table, or a collapsible section.
  • Inside a list, press Tab to nest a sub-list and Shift+Tab to go up a level.
  • Multi-line code block: use ＋▾ → Code block. Inside it, Enter = new line, Tab = 2 spaces, Enter on an empty line exits the block.
  • A▾ = text color, highlight, and insert date/time (select text first for color).
  • 💾 saves. The ⋯▾ menu has Save as…, Export PDF, Toggle Raw source, and word-wrap. A literal <br> renders as a line break.
  • Auto-save writes back to the file automatically. Requires a Chromium-based browser (Chrome/Edge) for folder access.
