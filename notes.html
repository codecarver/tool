Notes (Markdown)

A WYSIWYG Markdown notes editor. Open a local folder on the left, edit on the right, auto-save.

No folder opened

    Click Open Folder to pick a local folder (the browser will ask for permission). .md/.txt files appear on the left. Click a file to open; type to edit. Toolbar formatting (bold/italic/heading/list) is stored as Markdown. Inside a list, press Tab to create a sub-list (nested) and Shift+Tab to go up a level. For a multi-line code block: click ▤ Code (or select multi-line text then click). Inside the block, Enter = new line, Tab = 2 spaces, and Enter on an empty line exits the block. There is also text color & highlight (select text first), insert date/time, a collapsible section, tables, and PDF export. Use Raw to view/fix the underlying Markdown directly. Auto-save writes back to the file automatically. Requires a Chromium-based browser (Chrome/Edge) for folder access.
