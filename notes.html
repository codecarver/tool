Notes (Markdown)

A WYSIWYG Markdown notes editor. Open a local folder on the left, edit on the right, auto-save.

How to use
  • Click Open Folder to pick a local folder. .md/.txt files appear on the left; click a file to open, or use the ⋯ button to rename/delete.
  • Type to edit. Toolbar formatting (bold/italic/heading/list) is stored as Markdown.
  • Inside a list, press Tab to nest a sub-list and Shift+Tab to go up a level.
  • Multi-line code block: click ▤ Code (or select text then click). Inside it, Enter = new line, Tab = 2 spaces, Enter on an empty line exits the block.
  • Also: text color & highlight (select text first), date/time, collapsible sections, tables, and PDF export.
  • Use Raw to view/fix the underlying Markdown (Wrap toggles word wrap). A literal <br> renders as a line break.
  • Auto-save writes back to the file automatically. Requires a Chromium-based browser (Chrome/Edge) for folder access.
