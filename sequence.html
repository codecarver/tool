Write interactions on the left, the diagram renders automatically on the right.

How to use
  • A -> B: Message = solid arrow, A --> B: Message = dashed, A -x B: Message = failed (X).
  • Add [red] to a message for a red line. Self-loop: A -> A: Internal process.
  • Overall title: title: Title. Separator: --- or --- text. Note: note: text.
  • Line break in a message: type \n (e.g. A -> B: line1\nline2). All syntax is optional.
  • Use Open Folder on the left to work with local .json files (auto-save, rename, delete).
