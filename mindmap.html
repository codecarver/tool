Mind Map Sederhana

Susun ide dengan drag & drop, ciutkan/perluas cabang, lalu simpan atau impor sebagai file JSON. Semua berjalan di browser Anda.

100%

Tips: klik kanan node untuk menu (tambah anak, ubah teks, tandai selesai, deskripsi, ciutkan, hapus). Klik dua kali teks untuk mengubah cepat — Enter baris baru, Ctrl+Enter/klik di luar untuk simpan, Esc batal. Badge angka pada node = jumlah anak; klik badge untuk perluas/ciutkan. Titik biru = ada deskripsi. Mode Auto merapikan posisi otomatis; Manual bebas seret. Ctrl+seret untuk menggeser panel. Perubahan tersimpan otomatis di browser ini (tetap simpan file JSON untuk cadangan/pindah perangkat).
