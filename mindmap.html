Simple Mind Map

Organize ideas with drag & drop, collapse/expand branches, then save or import as a JSON file. Everything runs in your browser.

100%

Tips: right-click a node for the menu (add child, edit text, mark done, description, collapse, delete). Double-click text to edit quickly — Enter for a new line, Ctrl+Enter/click outside to save, Esc to cancel. The number badge on a node = child count; click the badge to expand/collapse. A blue dot = has a description. Auto layout tidies positions automatically; Manual lets you drag freely. Ctrl+drag to pan the canvas. On touch devices, press and hold a node to open its menu; use the zoom buttons to zoom. Changes are auto-saved in this browser (still save the JSON file for backup/moving devices).
