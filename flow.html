How to use
  • Add shapes from the toolbar. Drag a node to move it. Drag the corner handle to resize.
  • Right-click a node for its menu (edit text, connect arrow, color, group, delete). Double-click text to edit quickly.
  • On a line: drag the blue handle to bend it, double-click to add a label, or right-click for the menu (label / straighten / curved or elbow style / delete).
  • Use + Text to write free text outside shapes.
  • Drag on empty space to select multiple nodes (or Shift+click), then right-click → Group to move them together (Ungroup to undo).
  • On touch devices, press and hold a node or line to open its menu.
  • Use Open Folder on the left to work with local .json files (auto-save, rename, delete).
