Flow Diagram

Susun alur proses: tambah node, seret, dan hubungkan dengan panah.

100%

Seret node untuk memindah. Klik kanan node untuk menu (ubah teks, hubungkan panah, warna, hapus). Klik dua kali teks node untuk mengubah cepat. Pada garis: seret titik biru untuk melengkungkan, klik dua kali garis untuk beri keterangan, atau klik kanan garis untuk menu (keterangan/lurus/gaya lengkung atau siku/hapus). Gunakan + Teks untuk menulis teks bebas di luar gambar. Seret di area kosong untuk memilih beberapa node sekaligus (atau Shift+klik satu per satu), lalu klik kanan → Grup agar bergerak bersama (klik kanan → Lepas grup untuk membatalkan).
