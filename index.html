Diagram & Notes Tools

A set of tools that run entirely in your browser. Free, no login, no server — data stays on your device.

🧠 Mind Map

Organize branching ideas with drag & drop, collapse/expand, zoom, and export.

🔀 Sequence Diagram

Write interaction steps on the left, see the rendered diagram on the right.

📊 Flow Diagram

Build process flows with nodes and arrows between steps.

✏️ Free Diagram

Free canvas — pick shapes (rectangle, ellipse, diamond) and arrange freely.

WYSIWYG Markdown notes editor. Open a local folder, browse files, auto-save.
