Diagram & Notes Tools

Kumpulan alat bantu yang berjalan sepenuhnya di browser. Gratis, tanpa login, tanpa server — data tersimpan di perangkat Anda.

🧠 Mind Map

Susun ide bercabang dengan drag & drop, collapse/expand, zoom, dan ekspor.

🔀 Sequence Diagram

Tulis langkah interaksi di kiri, lihat representasi diagramnya di kanan.

📊 Flow Diagram

Buat alur proses dengan node dan panah antar langkah.

✏️ Free Diagram

Kanvas bebas — pilih bentuk (kotak, elips, wajik), susun sesukanya.

📝 Notes (Markdown)

Editor catatan WYSIWYG format Markdown. Buka folder lokal, jelajah file, auto-save.
