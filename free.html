How to use
  • Pick a shape from the toolbar to add a node. Drag to move. Drag the corner handle to resize.
  • Right-click a node for its menu (edit text, connect arrow, color, group, delete). Double-click text to edit (\n for a new line).
  • On a line: right-click for the menu (label / straighten / curved or elbow style / delete).
  • Enlarge a box then drop another box on top of it to make an object inside an object.
  • Use + Text to write free text outside shapes.
  • Drag on empty space to select multiple nodes (or Shift+click), then right-click → Group to move them together (Ungroup to undo).
  • On touch devices, press and hold a node or line to open its menu.
  • Use Open Folder on the left to work with local .json files (auto-save, rename, delete).
