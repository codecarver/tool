Free Diagram

Free canvas — pick shapes, arrange, and connect however you like.

100%

Pick a shape to add a node. Drag to move. Right-click a node for the menu (edit text, connect arrow, color, delete). Double-click text to edit quickly (use \n for a new line). On a line: right-click for the menu (label/straighten/curved or elbow style/delete). Enlarge a box then drop another box on top of it to make an object inside an object. Use + Text to write free text outside shapes. Drag on empty space to select multiple nodes (or Shift+click one by one), then right-click → Group to move them together (right-click → Ungroup to undo). On touch devices, press and hold a node or line to open its menu. Auto-saved in this browser.
