Kanvas bebas — pilih bentuk, susun, dan hubungkan sesukanya.

100%

Pilih bentuk untuk menambah node. Seret untuk memindah. Klik kanan node untuk menu (ubah teks, hubungkan panah, warna, hapus). Klik dua kali teks untuk mengubah cepat (pakai \n untuk baris baru). Pada garis: klik kanan untuk menu (keterangan/lurus/gaya lengkung atau siku/hapus). Perbesar sebuah kotak lalu taruh kotak lain di atasnya untuk membuat objek di dalam objek. Gunakan + Teks untuk menulis teks bebas di luar gambar. Seret di area kosong untuk memilih beberapa node sekaligus (atau Shift+klik satu per satu), lalu klik kanan → Grup agar bergerak bersama (klik kanan → Lepas grup untuk membatalkan). Tersimpan otomatis di browser ini.
